# Smart College — мобильное приложение (React Native + Expo)

Приложение для студентов и преподавателей ИТК. Работает через API сайта
`https://smartcollege.pythonanywhere.com/api/` (описание — `../API.md`).

Экраны: вход, главная («Следующая пара», долги, задания), неделя, задания и долги,
ИИ-агент (тот же агент на Gemini, что на сайте), профиль с темой (светлая/тёмная/как в системе).

## Запуск на телефоне (Expo Go)

1. Установите на телефон приложение **Expo Go** (Play Market / App Store).
2. На компьютере (нужен Node.js 20+):
   ```bash
   cd mobile
   npm install
   npx expo start
   ```
3. Отсканируйте QR-код из терминала: на Android — в Expo Go, на iPhone — камерой.
   Телефон и компьютер должны быть в одной Wi-Fi сети (или запустите `npx expo start --tunnel`).

Демо-входы: `student` / `demo12345` (студент), `teacher` / `demo12345` (куратор).

## Веб-версия (для проверки в браузере)

```bash
npx expo start --web
```

## Собрать APK для Android

Нужен бесплатный аккаунт https://expo.dev.
```bash
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview
```
Через 10–20 минут EAS даст ссылку на `.apk`, его можно поставить на любой Android.

## Где что

| Файл | Что внутри |
|------|------------|
| `App.js` | вход, хранение токена, нижнее меню, тема |
| `src/api.js` | запросы к API (адрес сервера — `API_URL`) |
| `src/screens.js` | экраны: вход, главная, неделя, задания, ИИ-агент, профиль |
| `src/ui.js` | карточки, пары, переключатель левой/правой недели |
| `src/theme.js` | цвета ИТК для светлой и тёмной темы |
