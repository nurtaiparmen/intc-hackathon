# Smart College · Инновационный Технический Колледж (г. Алматы)

Портал колледжа с ИИ для хакатона **NeuroHack 2026**. Команда группы **РПО6-24Р**
(куратор — Болатов Айкын Нұрғалымұлы): Пармен Нуртай, Алтынбек Султан,
Исмаилов Асанали, Айтматов Самандар.

- **Расписание по фото.** Преподаватель загружает скриншот, фото или Excel —
  Google Gemini читает таблицу и раскладывает пары по дням, человек проверяет и сохраняет.
- **ИИ-агент.** Студент спрашивает обычными словами («чё по парам завтра»), преподаватель
  командует («отмени 3 пару в пятницу») — агент сам вызывает функции сайта.
- **Всё видно сразу.** Какая пара идёт сейчас, замены, левая/правая неделя, задания, долги.
- Стиль ИТК, светлая и тёмная тема, мобильная версия с нижним меню.

## Запуск

Нужен Python 3.12+.

```bash
python -m venv venv
venv\Scripts\activate             # macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env            # впишите GEMINI_API_KEY (https://aistudio.google.com/apikey)
python manage.py migrate
python manage.py seed_demo        # группа РПО6-24Р: расписание, куратор, команда, задания
python manage.py runserver
```

Откройте http://127.0.0.1:8000. Пароль у всех демо-входов `demo12345`:

| Логин | Кто |
|-------|-----|
| `student` | Айтматов Самандар, студент РПО6-24Р (2 долга) |
| `teacher` | Болатов Айкын, куратор группы |
| `asanali`, `sultan`, `nurtay` | остальные студенты |
| `admin` | админка |

Страница «О проекте» открыта без входа: `/about/`.
Деплой на PythonAnywhere — [DEPLOY_PythonAnywhere.md](DEPLOY_PythonAnywhere.md).
JSON API для мобильного приложения (вход по токену, расписание, задания, ИИ-агент) — [API.md](API.md).

## ИИ

Google Gemini через OpenAI-совместимый API (`portal/llm.py`): основная модель
`gemini-3.5-flash-lite`, при перегрузке — повтор и запасные модели. Можно перейти на
Groq/Ollama, поменяв `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` в `.env`.
Без ключа сайт работает, агент отвечает в простом режиме по ключевым словам.

| Файл | Что внутри |
|------|------------|
| `portal/ai_services.py` | фото / Excel / текст расписания → JSON (Pydantic) → база |
| `portal/agent.py` | ИИ-агент: 14 инструментов, промпт, цикл, офлайн-режим |
| `portal/llm.py` | клиент модели: повторы, запасные модели, ошибки |
| `portal/models.py` | роли, группы, предметы, расписание с заменами, задания, сдачи |
| `portal/utils.py` | левая/правая неделя, расписание с заменами, долги |
| `portal/team.py` | команда и вклад (страница «О проекте») |
| `portal/knowledge/college.md` | база знаний агента |
| `portal/tests.py` | 65 тестов без интернета: `python manage.py test` |

Защита: расписание из ИИ сохраняется только после проверки человеком; студент ничего
не меняет, преподаватель — только свои группы; каждое действие агента проходит те же
проверки, что и формы; лимиты на длину и частоту вопросов.

## Ограничения прототипа

- Подгруппы не поддерживаются: разделённая ячейка понимается как левая/правая неделя.
- Лимит сообщений хранится в памяти процесса; SQLite — только для прототипа.
